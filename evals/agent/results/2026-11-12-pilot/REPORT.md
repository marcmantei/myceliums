# Agent benchmark: 2026-11-12-pilot

Does a coding agent answer code-understanding questions better, cheaper or faster when it has the myceliums MCP server? Generated by `python3 evals/agent/agent_eval.py report 2026-11-12-pilot` from `results.jsonl` and `meta.json` in this directory; method in [`../../README.md`](../../README.md).

## Setup

- **Date:** 2026-11-12
- **Agent:** Claude Code 2.1.322, `--model sonnet` (resolved: `claude-sonnet-5-5`), `--effort medium`, `--max-turns 40`, timeout 900 s per session
- **myceliums:** `myc 0.3.2` built from commit `c2cac9ca39cb` (binary sha256 `268c200c49429e5a…`)
- **Conditions:** *without* = the built-in tools `Read`, `Grep`, `Glob` and `ToolSearch`; *with* = the same plus the myceliums MCP server (54 tools, deferred behind `ToolSearch` as Claude Code does by default). Same prompt, model and limits; user settings, CLAUDE.md, hooks, plugins and skills disabled and checked in every transcript.
- **Tasks:** 30 over 3 pinned repositories, 3 repetitions per task and condition, 180 graded sessions (90 with, 90 without).
  - `fastapi` 0.162.5 (`5add7a458d62`, Python): index 7,370 symbols in 1,066 files
  - `fzf` v0.75.0 (`c7bf2b8eea25`, Go): index 2,817 symbols in 112 files
  - `hono` v4.13.18 (`f6fbaf0299c4`, TypeScript): index 10,538 symbols in 447 files
- **Grading:** set-based precision / recall / F1 of the final JSON answer against hand-verified gold sets; success = F1 ≥ 0.8.
- **Statistics:** repetitions are averaged within each task first; 95 % paired bootstrap intervals over tasks (10,000 resamples, percentile method).

## Notes

- The with condition adds only the MCP server: `myc setup-claude` also installs a SessionStart hook (re-index plus a status line in the session) and a PostToolUse hook; neither is part of this run.
- Claude Code defers MCP tool definitions by default: with myceliums attached, the agent saw the 54 tool names and the server's instructions ("WHEN TO USE MYCELIUMS (always try first for these tasks)"; checked in a separate dry run) but not the tool schemas until it called ToolSearch.
- FastAPI was indexed with docs/ excluded (index-time .myceliums.toml): with the 1,709 Markdown files in 13 languages the analysis produced 23,941 symbols and its community detection had not finished after 13 minutes, before any embedding. The agent could still read docs/.
- Gold amended after the run started: hono-dead-utils gained getFilePathWithoutDefaultDocument as an optional (neutral) item, because the question admits a transitive reading (it is called only by the unused getFilePath). Every session is re-graded from its stored answer. The fastapi-dead-deprecated question was reworded (called -> referenced) before any FastAPI session ran.
- Sessions ran in three batches by repository as the indexes became ready (fzf, then hono, then FastAPI); within a repository the order is repetition-major with the two conditions adjacent. The fzf batch stopped once at the account-utilisation guard (0.95) and was resumed with the guard at 0.97.
- The benchmark machine was heavily loaded by unrelated builds (load average 300-500 on 10 cores); wall times include that.
- `--effort medium` was fixed (the CLI default is served per model and would otherwise vary); `cost_usd` is the CLI's list-price estimate and depends on prompt caching across sessions.
