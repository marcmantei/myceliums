## Notes

- Calibration of the outcome eval (#153): condition none only, 6 of the 12 tasks (two per type), --max-turns 8 with the turn limit stated in the prompt. 5 of 6 succeeded: at the ceiling, so the main run tightened the budget (see 2026-11-21-outcome-calibration-t4).
- This run's prompt said that parallel tool calls count one turn each. The probe against the mock API showed that the CLI counts replies (parallel calls in one reply share a turn), so these sessions had up to seven rounds of tool calls and used two to five; the text was corrected before the 4-turn calibration and the main run.
