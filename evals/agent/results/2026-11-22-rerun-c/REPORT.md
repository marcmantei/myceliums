# Agent benchmark: 2026-11-22-rerun-c

A re-run of condition C of [`2026-11-22-scale`](../2026-11-22-scale/REPORT.md) (#163) at 10 and 40 turns with a newer myc and fresh indexes, compared, paired by task, with the committed #163 sessions of none and of the old C. Generated by `python3 evals/agent/agent_eval.py report 2026-11-22-rerun-c` from `results.jsonl`, `meta.json` and `tasks_snapshot.json` in this directory and the committed `results.jsonl` of `2026-11-22-scale`; method in [`../../README.md`](../../README.md).

## Setup

- **Date:** 2026-11-22 (the #163 sessions: 2026-11-22)
- **Agent:** Claude Code 2.1.330 (#163: 2.1.330), `--model sonnet` (resolved: `claude-sonnet-5-5`; #163: `claude-sonnet-5-5`), `--effort medium` (#163: `medium`)
- **Budgets:** `--max-turns 10` (stated in the prompt, timeout 360 s; #163: stated, 360 s); `--max-turns 40` (a safety cap, not stated in the prompt, timeout 480 s; #163: not stated, 480 s).
- **myceliums (C #171):** `myc 0.3.2` built from commit `d1edc390e0c4` (binary sha256 `4f59a4b2ada3c7bf…`); 9 MCP tools offered. C #163: `myc 0.3.2` from `951d041ff9e0` (sha256 `4ef9e803790e41b4…`).
- **Tasks:** 30 from `tasks/tasks-scale.json` (sha256 `5c5164668ae63dee…`, the file the #163 results are graded against), 1 repetition per task and budget; 60 graded C sessions.
  - `django` 5.1.4 (`2d4add11fd57`, Python): 15 tasks; fresh index 12,443 symbols in 828 files, 31,408 relationships, 12,443 embedded, not indexed: `tests/**`, `docs/**`, `js_tests/**`, `scripts/**`, `extras/**` (#163: 12,443 symbols in 828 files, 31,408 relationships)
  - `vue` v3.5.46 (`7de9e41b61b2`, TypeScript): 15 tasks; fresh index 15,750 symbols in 501 files, 20,566 relationships, 15,750 embedded, not indexed: `packages-private/**`, `changelogs/**`, `CHANGELOG.md` (#163: 15,750 symbols in 501 files, 19,544 relationships)
- **Primary analysis:** the 27 tasks without `django-tests-import-string`, `django-tests-number-format`, `django-tests-split-domain-port`. The fresh Django index again leaves out tests/ (index_exclude_extra tests/**, as in #153/#163): with tests/ the analysis by the current main did not finish (#172), so in C myceliums had no data for the three Django tests tasks; they stay out of the primary analysis. The 30-task numbers are given alongside.
- **Comparisons:** C (#171) against none (#163) and against C (#163), paired by task at the same budget. Same prompt, model alias, effort, turn limits, timeouts, built-in tools (`Read`, `Grep`, `Glob`, `Bash`), isolation and `myc setup-claude --scope project --no-agent` as #163; a fresh working copy and index copy per session.
- **Statistics:** tasks are the unit; 95 % percentile bootstrap intervals (10,000 resamples over tasks, paired); per budget an exact two-sided McNemar test on success; *all re-run budgets* averages each task over its budgets and uses an exact sign test. **No interval or p-value is corrected for multiple comparisons** (two budgets, two baselines, two task views, several metrics, repositories and task types); the repository and task-type tables are exploratory.
- **Time drift:** the none and old C arms ran on 2026-11-22 before this re-run, not interleaved with it; a change of the model behind the alias or of the service in between would show up as a difference, too.
- **Labels:** the gold sets of this task file were drafted by an agent from the AST and the type checker and are not reviewed (the #164 review left this set out).

## Notes

- Session accounting: 60 agent sessions (30 tasks x condition C x 10 and 40 turns x 1 repetition), every one graded on its first attempt: no retries (0 of the 5 allowed), no timeouts, no turn-limit hits; the longest took 269 s. Two probe sessions against the mock API (one per repository, condition C) used no model. The none and old C rows are the committed #163 sessions; none of them was re-run.
- Binary: myc 0.3.2 built in release mode from d1edc390e0c4 (main with #169, PR #170), sha256 4f59a4b2ada3c7bf701c3f1f28f292ecc0ebee0836926184b86b8af5ef732218. #163 ran 951d041ff9e0 (sha256 4ef9e803...). Claude Code 2.1.330 and the resolved model claude-sonnet-5-5 are the same in both runs.

Vue: the #163 configuration, 15,750 of 15,750 embedded in 3,831 s (built next to the first Django build); 20,566 relationships against #163's 19,544 (#169 resolves the @vue/* workspace packages); fingerprint over 266 files bb68578d8433bbab.... myc callers toRawType now lists 3 direct callers (#163: 0).
- Django with tests/: the planned index (myceliums' default configuration, agent_eval.py index --default-config django) parsed 41,842 symbols in 2,956 files with 328,884 relationships and embedded all 41,842 in 8,386 s; community detection then ran for more than 1.5 hours without finishing and the build was stopped (#172).
