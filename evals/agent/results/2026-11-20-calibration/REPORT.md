# Agent benchmark: 2026-11-20-calibration

Which integration layer makes a coding agent use myceliums, and does it help? Generated by `python3 evals/agent/agent_eval.py report 2026-11-20-calibration` from `results.jsonl`, `meta.json` and `tasks_snapshot.json` in this directory; method in [`../../README.md`](../../README.md).

## Setup

- **Date:** 2026-11-20
- **Agent:** Claude Code 2.1.329, `--model sonnet` (resolved: `claude-sonnet-5-5`), `--effort medium`, `--max-turns 40`, timeout 900 s per session
- **myceliums:** `myc 0.3.2` built from commit `6661198e1ad3` (binary sha256 `c911169eb3c7259c…`)
- **Tasks:** 10 from `tasks/tasks-hard-v1.json` over 3 pinned repositories, 1 repetition(s) per task and condition, 10 graded sessions.
  - `fzf` v0.75.0 (`c7bf2b8eea25`, Go): index 2,865 symbols in 112 files
  - `hono` v4.13.18 (`f6fbaf0299c4`, TypeScript): index 10,588 symbols in 447 files
- **Same in every condition:** prompt, model, effort, turn limit, timeout; built-in tools `Read`, `Grep`, `Glob` (+ `ToolSearch`); `--setting-sources project` (the working copy's `.claude/settings.json` and `CLAUDE.md` load, the user's do not); fresh working copy and index copy per session; transcripts checked for the expected tools, MCP server and subagents.
- **Grading:** set-based precision / recall / F1 against gold sets derived with compiler tooling; success = F1 ≥ 0.8.
- **Statistics:** repetitions averaged within each task; 95 % percentile bootstrap intervals over tasks (10,000 resamples), paired with condition `none` for the differences.
