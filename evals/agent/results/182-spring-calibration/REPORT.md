## Setup

- **Date:** 2026-11-23
- **Agent:** Claude Code 2.1.330, `--model sonnet` (resolved: `claude-sonnet-5-5`), `--effort medium`, `--max-turns 100`, timeout 1200 s per session
- **myceliums:** `myc 0.3.2` built from commit `388c6e1291fd` (binary sha256 `a42bffce8d3aec06…`)
- **Tasks:** 30 from `tasks/tasks-java.json` over 1 pinned repositories, 1 repetition(s) per task and condition, 30 graded sessions.
  - `spring-framework` v7.1.0 (`f2e4863de60e`, Java): index 145,670 symbols in 10,158 files
- **Same in every condition:** prompt, model, effort, turn limit, timeout; built-in tools `Read`, `Grep`, `Glob`, `Bash` (+ `ToolSearch`); `--setting-sources project` (the working copy's `.claude/settings.json` and `CLAUDE.md` load, the user's do not); fresh working copy and index copy per session; transcripts checked for the expected tools, MCP server and subagents.
- **Grading:** set-based precision / recall / F1 against gold sets derived with compiler tooling; success = F1 ≥ 0.8.
- **Statistics:** repetitions averaged within each task; 95 % percentile bootstrap intervals over tasks (10,000 resamples), paired with condition `none` for the differences.
