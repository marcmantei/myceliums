- **Statistics:** repetitions averaged within each task; 95 % percentile bootstrap intervals over tasks (10,000 resamples), paired with condition `none` for the differences.

## Notes

- Calibration for #163 (15 sessions, the allowance): condition none only, --max-turns 10 with the budget stated in the prompt, Bash added to Read/Grep/Glob, the same prompt as the main run's 10-turn arm; one session for each of 15 of the 35 candidates in tasks/tasks-scale-candidates.json (the file this run used; the frozen set is tasks/tasks-scale.json).
- Rule applied: a candidate is rejected as trivially solved when the agent reached F1 = 1.00 with at most two tool calls, and as impossible when it failed after reading the relevant code with a defensible but different reading of the question; none was impossible. Rejected as trivially solved: all five candidates that are not about calls (django-cfg-deploy-checks, django-cfg-empty-strings, django-cfg-safe-filters, vue-cfg-force-attrs, vue-cfg-unused-error-codes: one or two Bash calls, 5 to 11 s). The other ten are in the frozen set; 8 of them succeeded (target 30-80 %).
- With Bash the agent wrote its own scripts (for example a Python ast call-graph script for django-tc-conditional-escape) and solved most call-graph candidates within the budget; it stayed inside the checkout (and /tmp for its scripts) in every session.
